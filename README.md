# Reproducibility Files

## Description

This repository contains the R code and data used to perform the statistical analyses reported in the accompanying manuscript: L1–L2 Morphological Congruency Operationalisations in Explaining L2 Acquisition in Written Learner Data: Binary vs Gradient Approach. The analyses examine the relationship between alternative operationalisations of L1–L2 morphological congruency and the acquisition of English grammatical morphemes by Polish learners of English using learner corpus data.

## Contents

- `morphological_congruency.R` – complete R script reproducing all statistical analyses reported in the manuscript.
- `accuracy_congruency.xlsx` – input dataset used for the analyses.
- `output/` – output files generated by the R script.
- `morphological_congruency.Rproj` – optional RStudio project file.

## Software

The analyses were conducted using:

- R version 4.5.1 ("Great Square Root")
- dplyr 1.1.4
- boot 1.3-32
- writexl

## Running the analyses

1. Open `morphological_congruency.Rproj` in RStudio (recommended), or set the working directory to the project folder.
2. Run `morphological_congruency.R` from beginning to end.

The script automatically generates all output files in the `output/` directory.

## Reproducibility

The analyses are fully reproducible from the supplied dataset and R script. No manual intervention is required once the required packages have been installed.
